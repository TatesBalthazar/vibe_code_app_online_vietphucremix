# Pixel Art Asset Directory Structure (`/public/pixel/`)

Drop your custom PNG sprites into the following paths and set `PIXEL_BASE_ASSETS.useExternalPngs = true` in `src/data/pixelStudioData.ts`:

```
/public/pixel/
    base.png
    hair/
        default.png
    outfits/
        ao-dai.png
        ao-tu-than.png
        ao-ngu-than.png
        ba-ba.png
    accessories/
        khan-dong.png
        kieng-bac.png
        non-quai-thao.png
        ngoc-trai.png
        non-la.png
    footwear/
        sandal.png
        sneaker.png
        guoc-moc.png
```
